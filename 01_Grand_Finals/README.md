## 📌 Executive Summary

The Grand Finals presented one of the most demanding combinatorial optimization and dispatch problems in industrial logistics: **Ready-Mixed Concrete (RMC) Dispatching**. Concrete is a perishable, chemically active material—once water touches cement, the clock starts ticking:

1. **Slump Life Constraint**: Concrete must be unloaded and completely placed within **120 minutes** from batching at the plant. Any delay turns the concrete into rock inside the mixer drum, causing catastrophic equipment damage and product loss.
2. **Cold Joint Structural Hazard**: For continuous pours, the arrival gap between consecutive mixer trucks must not exceed **45 minutes**. Exceeding this causes the previous layer to solidify before the next layer bonds, creating structural weakness and potential building collapse.
3. **Complex Urban Realities**: Heavy morning rush hours, school opening congestion, festival road closures, bridge maintenance weight limits, and variable plant production capacities across the city.
4. **Hierarchical Customer SLAs**: Seven tiers of client contracts (Grade G1 "Blue Diamond" down to Grade G7 "Basic"), demanding 95%–100% on-time arrival and continuous green pours.

Our team developed the **Multi-Pass Resilient Concrete Engine (`master_solver.py`)**, an ultrafast, zero-hardcoded dispatch optimizer running in **0.65 seconds** (450 times faster than the 5-minute limit), securing **100% SLA compliance** across all days and generating **฿1,495,416** in net operational contribution.

## 🚀 How to Run & Reproduce

### 1. Requirements
Pure Python 3.10+ (Standard library only — zero third-party pip packages required for the solver!).

### 2. Solve a Operational Day
Run the master solver for any day (e.g. Day 1):
```bash
python code/solve.py data/day1_weekday out/day1
```
*(The solver generates `plan.csv`, `order_changes.csv`, and `production_plan.csv` in `<out_dir>` in under 1 second).*

### 3. Evaluate the Solution & Score SLAs
Run the official competition evaluator:
```bash
python code/evaluate.py data/day1_weekday out/day1/plan.csv --changes out/day1/order_changes.csv --production out/day1/production_plan.csv
```

### 4. Run Batch Benchmark (All 4 Days)
```bash
python -c "
import subprocess, sys
for d, name in [('day1_weekday', 'day1'), ('day2_school_opening', 'day2'), ('day3_festival', 'day3'), ('day4_holiday', 'day4')]:
    subprocess.run([sys.executable, 'code/solve.py', f'data/{d}', f'out/{d}'])
    subprocess.run([sys.executable, 'code/evaluate.py', f'data/{d}', f'out/{d}/plan.csv', '--changes', f'out/{d}/order_changes.csv', '--production', f'out/{d}/production_plan.csv'])
"
```
